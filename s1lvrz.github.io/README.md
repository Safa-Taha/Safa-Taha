# Mohamed Ashraf Ramadan — Personal Portfolio

A responsive, accessible, one-page engineering portfolio built with plain HTML, CSS, and JavaScript.

## Included

- Responsive desktop, tablet, and mobile design
- Dark and light themes
- Featured project cards
- Skills, experience, education, about, and contact sections
- Embedded PDF CV
- SEO and social-sharing metadata
- Keyboard-accessible navigation
- Reduced-motion support
- No frameworks or external dependencies

## Local Preview

Open `index.html` in a browser.

For a more accurate local server preview in VS Code, install the **Live Server** extension, right-click `index.html`, and select **Open with Live Server**.

## Publishing

Follow the Arabic beginner guide in `DEPLOYMENT_GUIDE_AR.md`.

## Content Basis

The website content is based on the supplied resume and the currently public GitHub repositories. Update the project descriptions and links whenever the repositories are expanded.
