Secure Dual MCU (STM32 + ESP32) Control Board

Pairs an STM32 for real-time control with an ESP32 for Wi-Fi connectivity, plus a dedicated FTDI UART so the STM32 can be accessed independently. An ATECC608 crypto element handles secure authentication for the board.

A power-bank style board that charges a single-cell Li-ion/Li-Po battery from USB-C, boosts it to 5V, and outputs over USB-C — with power-path switching so the load draws directly from USB when a cable is connected.
